# Routine quotidienne (heure d'Alger)
- 13h00 : lire le profil du jour (risque événementiel, régime, niveaux, expected move). Repérer les événements et leurs protocoles.
- 14h45 : deuxième snapshot ; noter les niveaux qui ont bougé.
- 15h15 : checklist pré-trade. Si STOP ou NO-TRADE, tu ne trades pas.
- Pendant : respecter fenêtres, limite de 2 trades, pause de 15 min après un SL.
- Après la clôture : journaliser chaque trade (contexte auto), noter une phrase sur l'exécution.
- Vendredi : lire le rapport hebdo ; choisir UNE règle à renforcer la semaine suivante.
