# P15 · Intégration MetaTrader 5 (MT5) en lecture seule pour le Journal de Bord
Tâches :
1. Client MT5 en lecture seule (`src/nqcockpit/broker/mt5_client.py`) : communication IPC locale avec le terminal MetaTrader 5 Windows via le package gratuit `MetaTrader5`. Récupération de l'état du compte (`account_info`), des positions ouvertes (`positions_get`) et de l'historique des deals (`history_deals_get`). AUCUNE fonction d'envoi d'ordres, d'altération de positions ou de trading actif (stricte conformité avec le principe R9 : "l'outil prépare, discipline et mesure, il n'exécute aucun ordre").
2. Statut honnête : détection et affichage systématique des statuts OK et DÉGRADÉ avec motif explicite (terminal absent, terminal non démarré, identifiants erronés, absence de dépendance). Aucune interpolation, aucun solde inventé ni trade fictif.
3. Sécurité des identifiants dans `.env` : lecture et écriture ciblée des clés `MT5_LOGIN`, `MT5_PASSWORD`, `MT5_SERVER` (et options de terminal) dans le fichier `.env` existant sans altérer les autres entrées. Masquage strict du mot de passe dans l'interface et interdiction absolue de journalisation en clair dans les logs structurés.
4. Passerelle vers le Journal de bord SQLite : conversion des transactions MT5 en instances `TradeEntry` avec calcul automatique du R, identification des sens (BUY/SELL), réconciliation des stops/targets, détection des fenêtres de négociation et déduplication contre les enregistrements existants. Conversion rigoureuse des horodatages serveur broker vers `America/New_York` (séance) et `Africa/Algiers` (affichage/kill zones) via `zoneinfo`.
5. Interface utilisateur Journal (`src/nqcockpit/ui/journal_page.py`) : intégration d'une sous-section dédiée pour la configuration MT5, visualisation du statut temps réel et bouton d'action "Importer depuis MT5", en complémentarité avec l'importation de fichiers CSV.
6. Suite de tests unitaires et d'intégration (`tests/test_p15_mt5_integration.py`) : simulation par mocks de l'ensemble des scénarios de connexion, d'erreur IPC, de conversion temporelle et de persistance SQLite.
Critères d'acceptation : prompt P15 documenté selon les standards du projet ; statut DÉGRADÉ explicite en cas d'absence du terminal MT5 ; mot de passe masqué et inviolabilité du fichier `.env` ; absence totale de code d'exécution d'ordres ; tests unitaires avec mocks verts ; validation `ruff` et `pytest` sans régression ; ADR documenté dans `docs/DECISIONS.md`.
